# fashion-flatlay-retouch

## Purpose
将输入的服装图片精修为符合电商标准的白底平铺产品图。

该 Skill 专注于：
- 精准识别服装主体
- 输出纯白背景产品图
- 去除随机褶皱、污渍、线头、起球、脏污
- 优化版型与平铺姿态，使其自然挺括、左右对称
- 严格保留原商品的颜色、面料、结构、图案、辅料和工艺细节
- 强化真实纺织质感
- 输出适合电商平台的主图、背面图与细节图

## Use When
在以下场景调用本 Skill：
- 需要将服装图精修为白底平铺主图
- 需要整理不平整的服装平铺图
- 需要去除褶皱、线头、污渍、起球
- 需要将实拍服装整理成更标准的电商产品图
- 需要输出背面平铺图
- 需要输出服装细节图（领口、袖口、腰头、下摆、面料微距等）
- 需要在不改变商品本身的前提下提升电商展示质量

## Do Not Use When
以下情况不要直接套用本 Skill，除非用户明确要求：
- 用户要做模特上身图，而不是白底平铺图
- 用户要做海报、宣传图、场景图
- 用户要做强风格化艺术图，而不是写实电商图
- 用户要故意改变颜色、图案、面料、辅料或结构
- 用户上传的主体不是服装商品，而是其他类别产品

## Input Requirements

### Required Inputs
至少提供以下内容之一：
1. 一张服装主图
2. 一张待精修服装图片

### Optional Inputs
如有则优先参考：
- 颜色参考图
- 面料参考图
- 辅料参考图（纽扣、拉链、挂饰、肩带滑扣、胸针等）
- 工艺参考图（烫钻、提花、刺绣、植绒、蕾丝等）
- 指定输出模式（主图 / 背面图 / 四张细节图 / 单张细节图）
- 指定画幅（默认主图 3:4，细节图 4:3）

## Output Modes

### Mode A：主图
- 纯白背景 `RGB(255,255,255)`
- 主体完整居中
- 正视平视平铺
- 无明显阴影
- 商业电商摄影质感
- 8K 高清质感
- 画幅默认 `3:4`

### Mode B：背面图
- 与主图风格、曝光、白平衡一致
- 保留后片结构、分割、图案和辅料
- 画幅默认 `3:4`

### Mode C：四张独立细节图
输出四张独立图片，禁止拼图：
- 白底
- 单张单部位
- 默认画幅 `4:3`
- 8K 高清
- 每张图突出一个细节部位

常见细节位点：

#### 上衣
1. 领口特写
2. 袖口 / 肩带特写
3. 下摆特写
4. 面料微距

#### 裤装
1. 腰头特写
2. 口袋 / 拉链 / 纽扣特写
3. 裤脚 / 下摆特写
4. 面料微距

#### 裙装
1. 腰头特写
2. 口袋 / 挂饰 / 连接位特写
3. 下摆特写
4. 面料微距

### Mode D：单张指定细节图
根据用户指定，仅输出某一个部位，如：领口、袖口、腰头、下摆、面料微距。

## Core Principles

### Principle 1：商品身份锁定优先
在任何精修开始前，先锁定以下商品身份信息，并在整个过程中保持不变：
- 颜色
- 面料
- 版型
- 结构
- 图案
- 文字
- 辅料
- 工艺

### Principle 2：允许优化展示，不允许篡改商品
允许：
- 去褶皱
- 去线头
- 去污渍
- 去起球
- 整理轮廓
- 调整平铺姿态
- 轻微优化立体感
- 提高清晰度
- 提升材质辨识度

禁止：
- 改变商品原本颜色
- 改变商品面料类别
- 改变版型比例
- 改变图案位置、数量、密度或样式
- 改变辅料位置、数量、造型
- 改变文字内容
- 省略或虚化关键细节

### Principle 3：真实电商摄影感优先
输出必须写实、干净、高清、自然、具有商业电商感；禁止夸张 AI 风格、过度锐化、塑料感和假材质感。

## Mandatory Preservation Rules

### 1. Color Preservation
- 严格保留原商品颜色
- 禁止色偏
- 禁止将暖色改冷色
- 禁止将浅色压暗或将深色漂浅
- 禁止局部明暗不一致导致颜色失真

### 2. Fabric Preservation
- 严格保留面料种类和真实视觉质感
- 必须呈现真实纺织结构
- 禁止涂抹感、塑料感、油画感
- 禁止将梭织变成针织
- 禁止将提花变成印花
- 禁止将雪纺变成厚棉质感

### 3. Structure Preservation
必须保留：领口、肩线、门襟、袖型、袖口、腰头、口袋、肩带、裙摆、下摆、裤腿、里外层关系、荷叶边、花苞边、层叠结构。

禁止：结构消失、结构错位、左右不对称、衣长/袖长/裙长/裤长异常改变、轮廓不自然塌陷或僵硬。

### 4. Pattern Preservation
必须严格保留：格纹、条纹、波点、提花、印花、刺绣、字母、图案贴布、植绒。

禁止：新增、删除、复制、缩放、拉伸、旋转、错位、模糊、断裂。

### 5. Accessory Preservation
必须保留：纽扣、拉链、挂饰、胸针、肩带滑扣、铆钉、爱心扣、兔子纽扣、珍珠扣、金属件。

禁止：丢失、变形、数量错误、位置错误、尺寸错误、材质错误。

### 6. Craft Preservation
必须保留：烫钻、蕾丝、刺绣、提花、浮雕肌理、压褶、荷叶边、花边、植绒。

#### 烫钻
- 必须清晰可见
- 必须呈现立体水晶颗粒感
- 不可丢失
- 不可模糊
- 不可变成印花点、白点或噪点
- 数量、位置、密度必须正确

#### 蕾丝
- 花型必须正确
- 层次必须清晰
- 不能糊成普通白边
- 不能变成抽象纹理

#### 刺绣 / 字母
- 文案必须正确
- 质感要像刺绣或原工艺
- 禁止乱码、错字、糊字

## Category-Specific Workflow

### Tops
重点检查：领口、肩线、左右袖长、袖口、下摆、胸前图案/刺绣/字母。

### Bottoms
重点检查：腰头、左右裤腿、裤脚、口袋结构、拉链/纽扣/腰袢、面料垂感。

### Skirts
重点检查：腰头、裙摆层次、荷叶边/花苞边、左右轮廓、图案连续性、下摆曲线。

### Dresses / Layered Garments
重点检查：内外搭关系、肩带宽度长度及连接点、胸前抽褶、多层裙摆关系、装饰件位置。

## Standard Workflow

### Step 1：Identify the Product
识别服装主体和类别，排除手、手指、桌面边缘、支撑物、杂物、挂钩、夹子、阴影污染、环境背景。

### Step 2：Lock Product Identity
锁定颜色、面料、轮廓、图案、工艺、辅料、文字和特殊结构。

### Step 3：Arrange Flat Lay Form
将服装整理为标准电商平铺状态：主体完整、左右平衡、自然挺括、正视平视、不僵硬、不像纸片。

### Step 4：Retouch
- 去除随机褶皱
- 修复线头、起球、污渍
- 优化边缘
- 修正局部塌陷
- 提升平整度
- 保留真实纹理
- 增强面料可读性

### Step 5：Standardize the Background
背景统一为纯白 `RGB(255,255,255)`，无脏污、无灰底、无杂色、无环境感、无台面边缘、无明显接地阴影。

### Step 6：Final QC
检查：
- 是否色偏
- 是否丢失细节
- 是否面料错误
- 是否结构变形
- 是否左右不对称
- 是否图案错位
- 是否辅料缺失
- 是否白底不纯
- 是否有阴影
- 是否有明显 AI 感

## Detail Shot Rules

### General Rules
- 每张细节图只表现一个核心部位
- 禁止四宫格拼图
- 禁止多个位点混在一张
- 白底、清晰、局部放大
- 保持与主图一致的颜色与材质表现

### Fabric Macro Rules
面料微距图必须：
- 面料占满全屏
- 无背景
- 展示真实纹理
- 默认三道连续柔和波形
- 禁止拉伸变形
- 若原面料有格纹、提花、烫钻、植绒等，必须同步准确呈现

## Negative Rules
绝对禁止：
- 改变原商品颜色、面料或结构
- 版型畸变、左右不对称
- 图案新增、删除、复制、缩放、错位
- 文字错误、刺绣错误、蕾丝花型错误
- 拉链、纽扣、挂饰、肩带滑扣丢失
- 烫钻丢失或变平面图案
- 格纹错误、波点错误
- 面料被磨皮
- 白底不纯、灰底、脏底、明显阴影
- 边缘发虚、纸片感、塑料感
- 过度锐化、过度磨皮
- 明显 AI 合成痕迹
- 乱码、细节糊掉

## Quality Bar
输出必须达到：
- 适合电商平台上架
- 商品主体完整清晰
- 背景纯净
- 画面高级整洁
- 材质真实
- 版型自然挺括
- 细节完整
- 无明显瑕疵
- 无 AI 失真感
