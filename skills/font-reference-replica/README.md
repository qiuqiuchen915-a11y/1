# font-reference-replica

A fidelity-first Skill for reconstructing typography from reference images.

## Recommended invocation

```text
按 $font-reference-replica 执行。
参考图：图1
目标文字：你的文字
要求：字体、字形比例、字距、描边、颜色、纹理、阴影全部严格复刻，禁止相似字体替代。
```

## Accuracy note

For the same text already visible in a good reference, direct extraction/tracing can approach pixel-level reconstruction. For characters that never appear in the reference, exactness cannot be guaranteed without the original font/vector source or enough glyph samples.
